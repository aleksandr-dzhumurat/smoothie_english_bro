# Unit 105 — Comparative 1 (cheaper, more expensive etc.)

# Theory

## A What a comparative is

We use a comparative to compare two things or two situations:

- Shall we take the bus or a taxi? — Let's take the bus. It's **cheaper**.
- Don't take a taxi. It's **more expensive**.

After a comparative we can add *than* (see Unit 107): *Taking the bus is cheaper than a taxi.* / *A taxi is more expensive than the bus.*

## B -er or more …?

| use -er | use more … |
|---|---|
| one-syllable words: *cheap → cheaper, tall → taller, big → bigger, safe → safer* | words of two or more syllables: *more modern, more useful, more interesting, more careful* |
| two-syllable adjectives ending in **-y** (-y → -ier): *happy → happier, busy → busier, funny → funnier, early → earlier* | adverbs ending in **-ly**: *more slowly, more clearly, more carefully, more often* |

(Spelling rules — *big → bigger*, *safe → safer* — are in Appendix 6.)

Examples in contrast:

- Lena is **taller** than her brother. / Lena is **more athletic** than her brother.
- The second test was **easier** than I feared. / The second test was **more demanding** than I feared.
- Could you type a bit **faster**? / Could you speak a bit **more clearly**?
- I want a **bigger** flat. / I want a **more central** flat.

A few two-syllable adjectives take **either** form: *clever, narrow, quiet, shallow, simple*. *Is there a quieter room? / a more quiet room?* — both are fine.

Common mistakes:

❌ more cheap ✅ cheaper
❌ more easy ✅ easier
❌ interestinger ✅ more interesting
❌ more fast ✅ faster

## C Irregular comparatives

| base | comparative |
|---|---|
| good / well | better |
| bad / badly | worse |
| far | further (or farther) |

- The team played **better** in the second half.
- My cold is getting **worse**, not better.
- The campsite was **further** from the lake than the map suggested.

*Further* (but not *farther*) also means "additional / more": *Are there any further questions?* (= any more questions)

### Question 36

#### Question
Complete the sentence: "This café is always packed. Let's find somewhere ______."

#### Answer
The correct answer is *quieter*. *Quiet* is one of the two-syllable adjectives (*clever, narrow, quiet, shallow, simple*) that accept both *-er* and *more*, so *quieter* and *more quiet* are both possible — but *quieter* is the form offered here and is the more common one. *More quieter* uses both markers at once, which is never correct. *Quietter* is a spelling error: the consonant is not doubled because *quiet* does not end in a single stressed vowel + consonant. *Quiet* alone is not a comparative and does not fit "somewhere ___".

#### Correct variant
¯\_(ツ)_/¯

#### Variants
1. more quieter
2. quietter
3. quieter (Correct)
4. quiet

### Question 37

#### Question
Which sentence is correct?

#### Answer
The correct sentence is *Could you explain that more slowly, please?* *Slowly* is an adverb ending in *-ly*, and such adverbs form the comparative with *more*, not *-er*. *Slowlier* does not exist. *More slow* is wrong here because we need an adverb to describe *explain*, not an adjective. *Slower* is possible as an informal adverb in some contexts, but the book teaches *more slowly* for *-ly* adverbs, and *explain that slower* is not the form taught.

#### Correct variant
¯\_(ツ)_/¯

#### Variants
1. Could you explain that slowlier, please?
2. Could you explain that more slowly, please? (Correct)
3. Could you explain that more slow, please?
4. Could you explain that slowlyer, please?

#### Question
Spot the mistake: "I'm a badder driver than my sister, but a more careful one than my father."

#### Answer
The mistake is *badder*. *Bad* has the irregular comparative *worse*, so the sentence should read *I'm a worse driver than my sister*. *More careful* is correct: *careful* has two syllables and does not end in *-y*, so it takes *more*. The *than* after both comparatives is also correct.

### Question 40

#### Question
A receptionist says to a guest: "The old town is ______ than you'd think — about forty minutes on foot. And if you need any ______ information, just ask." Which pair fills both gaps?

#### Answer
The correct pair is *further / further*. In the first gap, both *further* and *farther* are possible for distance, but the second gap means "additional / more information", and only *further* has that meaning — *farther information* is wrong. So the pair that works for both gaps is *further / further*. *More far* is not a valid comparative of *far*.

#### Correct variant
¯\_(ツ)_/¯

#### Variants
1. farther / farther
2. more far / more
3. further / further (Correct)
4. farther / more far
