# Unit 84 — there … and it …

# Theory

## A there … introduces, it … refers back

We use **there + be** to mention something for the first time, to say that it exists or happens:
- There’s a market in the square on Saturdays.
- Sorry we’re late – there was an accident on the motorway. (❌ It was an accident)
- Prices have gone up. There has been a sharp increase in rents.

**It** refers to a specific thing, place, fact or situation that is already known:
- We tried the new café. It’s excellent. (It = the café)
- Nobody expected the team to win. It was a real shock. (It = that they won)

Compare in one sentence:
- I love this city. **There**’s so much going on. **It**’s a fascinating place.

**There** can also be an adverb of place (= in/at/to that place):
- The flat is empty. There’s nobody living there. (= in the flat)

## B there + modal / other verb forms

*there* combines with many verb forms, not just *is/was*:

| there will be | there must have been | there is sure to be |
|---|---|---|
| there must be | there should have been | there is bound to be |
| there might be | there would have been | there is going to be |
| there used to be | there could be | there is likely / supposed to be |

- "Is there a train after midnight?" "There might be. Let me check."
- If the roads were wider, there wouldn’t be so many jams.
- The lights were on – there must have been someone inside.
- There’s bound to be a pharmacy near the station.

Contrast *there* and *it* with these forms:
- They live next to the airport. **There** must be a lot of noise. / **It** must be very noisy. (It = living there)
- **There** used to be a bakery here, but it closed. / That shop **used to be** a bakery. (It = the shop)
- **There**’s sure to be a queue. / There’s a queue, and **it**’s sure to be long. (it = the queue)

## C it as an empty subject

We use **it** at the start of sentences instead of an infinitive or clause as subject:
- It’s dangerous to cycle without lights. (❌ To cycle without lights is dangerous)
- It took ages to find a parking space.
- It’s a pity (that) you missed the show.
- It’s not worth arguing about it.

**It** is also used for distance, time and weather:
- How far is it to the coast from here?
- It’s been years since we last met.
- It’s freezing today.

Compare weather sentences: **It** was foggy. **but** **There** was thick fog. (it + adjective, there + noun)

**See also:** Unit 45B (supposed to), Unit 63A (it’s worth / there’s no point), Unit 65E (sure to / bound to), Unit 97 (there is + -ing/-ed).

#### Question
Which sentence describing the weather is grammatically correct?

#### Answer
**"It was very windy, and there was a lot of rain."** With an adjective (*windy*) we use *it*; with a noun (*a lot of rain*) we say that it existed with *there*. *There was very windy* wrongly uses *there* with an adjective, and *it was a lot of rain* wrongly uses *it* with a noun that is being introduced.
