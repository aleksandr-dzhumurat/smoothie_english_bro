# Unit 102 — so and such

# Theory

## A so + adjective/adverb, such + noun

The basic rule is about what follows the word:

| so + adjective / adverb | such (+ adjective) + noun |
|---|---|
| so cold, so cheap, so carefully | such a mess, such weather, such friends |
| The exam was so hard. | It was such a hard exam. |
| He drove so slowly. | He is such a slow driver. |

❌ It was a so boring film. ✅ It was such a boring film.
❌ They are so kind neighbours. ✅ They are such kind neighbours.

With a singular countable noun the order is *such a* (not *a such*): *such a big mistake*.

## B Making the meaning stronger

Both words intensify, like *really*:

- The lecture finished at midnight. I'm so sleepy. (= really sleepy)
- Thanks for the weekend. We had such a lovely time. (= a really lovely time)
- Marco never worries about anything. He's such a relaxed person.

They introduce a result with *that*, and *that* is usually dropped in speech:

- I was so nervous (that) I forgot my own phone number.
- It was such a heavy suitcase (that) the two of us couldn't lift it.

## C so / such = "like this", "to this degree"

*So* and *such* can also refer to the degree that is actually the case:

- I knew the flat was small, but I didn't expect it to be so small. (= as small as it is)
- I normally finish work at five. I don't usually stay so late.
- We drove for hours. I hadn't realised it was such a long journey.
- Who would believe such a story? (= a story like this)

Note *no such …* = "this does not exist": *There's no such thing as a free lunch.* / *He asked for Room 413, but there's no such room in this hotel.*

## D Common contrasts

| so | such |
|---|---|
| for so long | for such a long time (not *so long time*) |
| so far | such a long way |
| so much / so many | such a lot (of) |

- I haven't been to the theatre for so long. / … for such a long time.
- I didn't realise the station was so far. / … was such a long way.
- There was so much noise. / There was such a lot of noise.

#### Question
Spot the mistake: "I hadn't seen my cousin for so long time that I almost didn't recognise her."

#### Answer
The error is *so long time*. *Time* is a noun, so *so* cannot be used; the fixed patterns are *for so long* (with no noun) or *for such a long time*. Either *I hadn't seen my cousin for so long that …* or *I hadn't seen my cousin for such a long time that …* is correct. *Such long time* is wrong because *time* here is a singular countable noun and needs *a*.

#### Correct variant

### Question 37

#### Question
Your colleague says: "I looked for a train to a town called Brenmore, but the booking site says the place doesn't exist." How would you report this with *such*?

#### Answer
The correct sentence is *There's no such town as Brenmore.* The expression *no such + noun* means "a thing like this does not exist", and it is followed by *as* when we name the thing. *No so town* is impossible because *so* cannot go before a noun. *Not such a town* is not the idiomatic form for "does not exist"; *no such* is the fixed expression. *Such no town* has the words in the wrong order.

### Question 38

#### Question
Sofia is describing the traffic on her way to work. Which two sentences have the same meaning?
(a) There was so much traffic that I was late.
(b) There was such a lot of traffic that I was late.
(c) There was such much traffic that I was late.
(d) There was so a lot of traffic that I was late.

#### Answer
Sentences (a) and (b) are both correct and mean the same thing. *So much / so many* is used with *so*, while the equivalent with *such* is *such a lot (of)*. Sentence (c) is wrong because *such* cannot be followed directly by *much*. Sentence (d) is wrong because *so* cannot be followed by *a lot of* — the article *a* signals a noun phrase, which requires *such*.

#### Correct variant
¯\_(ツ)_/¯

#### Variants
1. (a) and (c)
2. (b) and (d)
3. (a) and (b) (Correct)
4. (c) and (d)
