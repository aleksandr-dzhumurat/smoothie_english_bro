# Unit 90 — all / every / whole

# Theory

## A everybody / everyone / everything vs all

For "all people" or "all things" as a subject or object on its own, English uses **everybody / everyone / everything**, not *all*:
- Everyone enjoyed the barbecue. (❌ All enjoyed the barbecue)
- Rosa thinks she knows everything. (❌ knows all)
- The trip went badly – everything went wrong.

**all** is normally used in these patterns:

| pattern | example |
|---|---|
| all + noun | All the guests were on time. / All my cousins live abroad. |
| all of + us / you / them | All of us were on time. |
| we / you / they … all … | We were all on time. (see Unit 110D) |
| all about … | She knows all about wine. |
| all … = the only thing(s) | All I want is a quiet weekend. (= the only thing I want) |

## B whole and all

**whole** = complete, entire. It goes mostly with **singular countable** nouns and is preceded by *the / a / my* etc.:
- Did you watch the whole series?
- Nils has spent his whole career at one firm.
- I was so hungry I ate a whole pizza.

We do **not** normally use *whole* with **uncountable** nouns (money, water, information …). Use **all the** instead:
- Did you spend all the money? (❌ the whole money)
- I read all the information twice. (❌ the whole information)

Compare: *I read the whole report* (countable) **but** *I read all the advice* (uncountable).

## C every day / all day / the whole day

**every** = how often something happens:
- We go swimming every Tuesday. (❌ all Tuesdays)
- A tram comes every eight minutes.
- The dentist checks my teeth every six months.

**all day / the whole day** = from the beginning of the day to the end:
- It snowed all day. / It snowed the whole day.
- He didn’t speak all evening. / … the whole evening.

Note: **all day, all week, all night** – no *the* (❌ all the day).

**all the time** vs **every time**:
- The baby cries all the time. (= continuously, always)
- Every time I wash the car, it rains. (= on each occasion)

## D every / everybody / everything are singular

They take a **singular verb**:
- Every ticket has been sold.
- Everybody was late. (❌ were late)

But we refer back to *everybody / everyone* with **they / them / their**:
- Everyone said they had enjoyed themselves.

**See also:** Units 69–70 (countable and uncountable), Unit 88 (all / all of), Unit 91 (each and every; every one), Unit 110C (all).

### Question 36

#### Question
Which sentence is wrong, and how should it be corrected?

A) Everybody clapped at the end.
B) All I need is a good night’s sleep.
C) All were delighted with the result.
D) We were all delighted with the result.

#### Answer
**C is wrong** (or at least very unnatural). *All* is not normally used on its own to mean "all people"; we say **Everybody was delighted with the result.** A is correct, B shows *all* = "the only thing", and D shows the pattern *we … all …*, both fine.

#### Correct variant
¯\_(ツ)_/¯

#### Variants
1. A — it should be *All clapped at the end*.
2. B — it should be *Everything I need is a good night’s sleep*.
3. C — it should be *Everybody was delighted with the result*. (Correct)
4. D — it should be *All of we were delighted*.

### Question 40

#### Question
Which sentence is grammatically correct?

#### Answer
**"Everyone has finished, so they can leave."** *Everyone* is singular and takes *has*, but we refer back to it with *they*. *Everyone have* uses a plural verb; *everyone has … he can* is not the neutral form the book teaches and would exclude women; *every people* is wrong because *every* takes a singular noun, and *people* is plural.

#### Correct variant
¯\_(ツ)_/¯

#### Variants
1. Everyone have finished, so they can leave.
2. Everyone has finished, so they can leave. (Correct)
3. Every people has finished, so they can leave.
4. Everyone has finished, so he can leave.
