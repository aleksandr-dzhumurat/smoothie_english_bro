# Unit 95 — Relative clauses 4: extra information clauses (1)

# Theory

## A Two types of relative clause

| | Type 1 (defining / identifying) | Type 2 (extra information) |
|---|---|---|
| purpose | tells us **which** person or thing (or what kind) we mean | adds **extra** information about a person or thing we already know |
| example | The nurse who treated my father was very patient. | My aunt Rosa, who lives in Lisbon, is a translator. |
| example | I work for a firm that produces software. | Daniel told me about his new flat, which he loves. |
| example | We ate at the restaurant (that) you suggested. | We ate at the Blue Fig, which a colleague suggested. |
| commas | no commas | commas before (and after) the clause |

In Type 1, "who treated my father" is necessary — without it we don't know which nurse. In Type 2, "my aunt Rosa" is already identified; the clause between commas could be removed and the sentence would still make sense.

## B who / which / that in the two types

In both types: **who** for people, **which** for things. But:

| | Type 1 | Type 2 |
|---|---|---|
| that | possible: the nurse who/that treated him; a firm which/that produces software | ❌ not possible: *Rosa, that lives in Lisbon* → Rosa, who lives in Lisbon |
| leaving out the object pronoun | possible: the restaurant (that/which) you suggested; someone (who/that) I hadn't seen for years | ❌ not possible: We ate at the Blue Fig, which a colleague suggested. / Yesterday I ran into Priya, who I hadn't seen for years. |
| whom | rarely used | possible when it is the object: Yesterday I ran into Priya, whom I hadn't seen for years. |

Summary of Type 2: always use *who* or *which* (never *that*), never omit them, and use commas.

## C whose and where in both types

Both *whose* and *where* work in both types of clause:

| Type 1 | Type 2 |
|---|---|
| We stopped to help a driver whose engine had overheated. | Marco, whose engine had overheated, was waiting by the roadside. |
| What's the name of the town where you were born? | Emma has just come back from Kyoto, where her son is studying. |

## Common mistakes

- ❌ *My father, that is a pilot, is often away.* ✅ My father, who is a pilot, is often away.
- ❌ *The bridge, which was built in 1900 is closed.* ✅ The bridge, which was built in 1900, is closed. (both commas)
- ❌ *The colleague, who sits next to me, is Spanish.* — if the clause identifies which colleague, no commas: The colleague who sits next to me is Spanish.

#### Answer
The correct sentence is "My grandmother, **who** still swims every day, is ninety." ### Question 24

#### Question
Read the two sentences. Which one is a Type 1 (identifying) clause and therefore correctly has **no** commas?
(a) "The bicycle that I bought last month has already been stolen."
(b) "My bicycle which I bought last month has already been stolen."

#### Answer
Sentence (a) is correct as it stands: "the bicycle that I bought last month" tells us which bicycle, so it is a Type 1 clause and takes no commas. Sentence (b) is wrong as written: "my bicycle" is already identified, so the clause is extra information and needs commas — "My bicycle, which I bought last month, has already been stolen." Option 3 is wrong because Type 1 clauses do allow *that*. Option 4 is wrong because (b) is not correct without commas.

#### Correct variant
¯\_(ツ)_/¯

#### Variants
1. Only (a) is correct; (b) needs commas around "which I bought last month". (Correct)
2. Only (b) is correct; (a) needs commas around "that I bought last month".
3. Neither is correct, because "that" can never be used in a relative clause about a thing.
4. Both are correct as they are.

### Question 26

#### Question
Choose the correct way to complete this sentence: "Mr Patel, ___ shop is on the corner, has lived here for forty years."

#### Answer
The correct word is **whose**: "Mr Patel, whose shop is on the corner, has lived here for forty years." *Whose* expresses possession (his shop) and can be used in both Type 1 and Type 2 clauses. *That* cannot be used in an extra-information clause and in any case does not express possession. *Who's* means *who is / who has*, so "who is shop" makes no sense. *Which* does not refer to people and is not possessive.

#### Correct variant
¯\_(ツ)_/¯

#### Variants
1. that
2. who's
3. which
4. whose (Correct)

### Question 27

#### Answer

Option 1 wrongly claims the sentence is fine. Option 3 adds commas but keeps *that*, which is impossible in a Type 2 clause. Option 4 uses *who* for a river.

#### Correct variant
