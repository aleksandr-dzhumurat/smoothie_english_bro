### Giving Time Estimates
- I think it should take me [*two days*].
- I'll have it done by …
- I expect to finish … by … (at the latest).

- I'm not sure it'd be possible.

### Useful phrases

- **fit tasks in the sprint**: deal with tasks in the current sprint. *We won’t be able to fit all the tasks in the current sprint.*
- **adjust the priority/scope**: change the importance of the task or the amount of work involved. *Adjusting the priority of these tasks might be a good option.*
- **allow time for something**: plan extra time for something. *We need to allow time for data cleansing.*
- **have a positive outcome**: have a good result. *The meeting with the stakeholder had a positive outcome.*
- **break something down**: decompose something. *Why don’t we break it down into manageable tasks?*
- **assign something to somebody**: choose who will do the task. *Let’s assign these tasks to team members.*
- **go over something**: look carefully at something. *Let’s go over the backlog to see what’s left from the previous sprint.*
- **leave something out**: not include something. *We will have to leave out the user behaviour research task this week. It’s a low priority task, so we can leave it out.*
- **be feasible**: be possible or reasonable. *I’m not sure this solution is feasible.*

This drop doesn’t seem to have anything to do with the number of downloads though.

**Maria:** So basically what you’re saying is that the number of downloads hasn’t changed, so the problem should lie somewhere in the updated onboarding. Is that correct?

**Amit:** Yes, pretty much.

**Maria:** Could you tell me why it was decided to change the onboarding and what screens were added?
